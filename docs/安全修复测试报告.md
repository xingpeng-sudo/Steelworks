## 二、详细修复内容

### 修复1：SQL 注入风险

**原问题：**
```python
# utils/sql_loader.py (旧代码)
sql = sql.format(**params)  # 不安全的字符串格式化
```

**修复方案：**
- 新增 `_validate_param_name()` 函数：验证参数名只允许字母、数字、下划线
- 新增 `_validate_param_value()` 函数：验证参数值不包含危险字符（`;`, `'`, `"`, `--`, `/*`, `*/`, `\x00`）
- 在参数替换前进行安全验证，非法参数抛出 `ValueError`

**修复后代码：**
```python
# utils/sql_loader.py (新代码)
def _validate_param_value(value) -> bool:
    """验证参数值是否安全"""
    if isinstance(value, str):
        dangerous_chars = [';', "'", '"', '--', '/*', '*/', '\x00']
        for char in dangerous_chars:
            if char in value:
                return False
    return True

# 在 load_sql 中调用验证
for key, value in params.items():
    if not _validate_param_name(key):
        raise ValueError(f"非法参数名: {key}")
    if not _validate_param_value(value):
        raise ValueError(f"参数值包含危险字符: {key}={value}")
```

**兼容性：** 原有合法调用（表名、列名等标识符）不受影响。

### 修复2：硬编码数据库凭据

**原问题：**
```python
# config/db_config.py (旧代码)
"user": os.getenv("DB_USER", "steelworks"),  # 默认密码暴露
"password": os.getenv("DB_PASSWORD", "steelworks"),
```

**修复方案：**
- 移除默认密码值
- 未配置环境变量时发出 `UserWarning` 警告
- 配置为空字符串（连接会失败，强制用户配置）

**修复后代码：**
```python
# config/db_config.py (新代码)
_db_user = os.getenv("DB_USER")
_db_password = os.getenv("DB_PASSWORD")

if _db_user is None and _db_password is None:
    import warnings
    warnings.warn(
        "数据库凭据未配置！请设置环境变量 DB_USER 和 DB_PASSWORD。",
        UserWarning
    )
    _db_user = ""
    _db_password = ""
```

**兼容性：** CI/CD 中已通过环境变量配置凭据，不受影响。

### 修复3：硬编码测试数据范围

**原问题：**
```python
# tests/test_rtd_mts_lg1/test_pointbof1no1.py (旧代码)
MIN_VALUE = 22220
MAX_VALUE = 22229  # 硬编码，不灵活
```

**修复方案：**
- 新增 `config/test_config.py` 配置文件
- 创建 `PointBOF1No1Config` 类管理测试配置
- 支持环境变量覆盖（`TEST_MIN_VALUE`, `TEST_MAX_VALUE`, `TEST_TABLE_NAME`, `TEST_COLUMN_NAME`）
- 保持原有默认值

**新增配置文件：**
```python
# config/test_config.py
class PointBOF1No1Config:
    TABLE_NAME = os.getenv("TEST_TABLE_NAME", "RTD_MTS_LG1_POINTBOF1NO1")
    COLUMN_NAME = os.getenv("TEST_COLUMN_NAME", "LUHOU_WENDU")

    @property
    def min_value(self) -> float:
        return float(os.getenv("TEST_MIN_VALUE", "22220"))

    @property
    def max_value(self) -> float:
        return float(os.getenv("TEST_MAX_VALUE", "22229"))
```

**兼容性：** 默认值与原硬编码值一致，原有测试逻辑不变。
